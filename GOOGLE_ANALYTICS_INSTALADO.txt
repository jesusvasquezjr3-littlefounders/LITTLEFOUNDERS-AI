🚀 PARA EMPEZAR - 3 PASOS SIMPLES:

  1️⃣  Obtén tu Measurement ID de Google Analytics
      → https://analytics.google.com/
      → Admin > Data Streams
      → Copia el ID (formato: G-XXXXXXXXXX)

  2️⃣  Crea el archivo: frontend/.env
      Agrega esta línea:
      VITE_GA_MEASUREMENT_ID=G-XXXXXXXXXX

  3️⃣  Reinicia el servidor:
      cd frontend
      npm run dev
