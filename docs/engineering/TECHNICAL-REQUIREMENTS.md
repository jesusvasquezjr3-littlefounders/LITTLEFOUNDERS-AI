# Technical requirements

> The index of technical requirements documents, one per feature, and the method for writing them.

> **Status: scaffold.** The structure is set; nothing below that is not marked as current state has been decided. Fill it in with the owner, then change the status to `draft` and, once approved, `accepted`.

## Role

A product requirement says what a feature does; a technical requirements document (TRD) says exactly how it will be built, secured and verified. No feature is implemented without an accepted TRD. The agent builds from the TRD, not from conversation memory.

## Read this when

- Starting a feature.
- Reviewing whether an implementation matches its design.
