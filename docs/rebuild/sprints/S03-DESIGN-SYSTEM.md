## S03.1 implementation and rationale

**Tokens.** `scripts/build-rebuild-tokens.mjs` now generates, from the Bible 02 YAML only: every type step as a `font` shorthand plus tracking (`--type-*`), including the display and numeral steps at the `app` container widths 640 and 1120 px from the YAML's own annotations (03 §3.2, fixed steps, no `clamp()`); the three elevation shadows (`--elevation-*`), which dark mode sets to `none` because "dark elevation is a lighter surface step, never a shadow" (02 §5); focus width, offset and colour (the colour stays a reference to `--primary-strong` so it follows the mode); the five duration and four easing tokens; and the press scale. The generator is now importable without side effects, its output is pinned by a unit test in addition to `spec:check`, and the same values are no longer hand-written anywhere else.

**Controls** (`rebuild/design/`, all exported from `controls.tsx`; no component owns a string, every caller passes translated, budgeted copy):

**Stylesheet** (`rebuild/design/controls.css`). Tokens only (no colour literal, no length other than the 2 px functional edge), logical properties only, no truncation or `clamp()`, no glass or gradient. Transitions exist only inside `@media (prefers-reduced-motion: no-preference)`, so reduced motion removes travel and keeps every state change (04 §3); presses scale to the `--press-scale` token with the standard easing and never the spring (D7). A forced-colours block restores functional edges where fills and shadows disappear. Selectors carry `.lf-rebuild`, so they outrank the root's element resets in `system.css` regardless of stylesheet order; the first-generation `.lf-button` base, accent, success, disabled and `.lf-field` rules are untouched.

**Preview catalogue** (`rebuild/preview/SystemGallery.tsx`, `/rebuild.html?screen=system`). Every control in every variant and state, in three locales and both modes, so the matrix can measure them. It is preview-only and not a product screen: every string meets its copy budget at the youngest band, but the first-view word total is deliberately not budgeted. Its 75 strings are in `i18n/*/rebuild.json` under `designSystem`, using the controlled glossary (coins/monedas/moedas, save/spend/share, approve/aprobar/aprovar, "Mentor" for the AI).

**Pure refactor of existing surfaces.** Only moves that leave every existing surface byte-identical were made: `Button` and `StatusMark` were re-implemented on the shared primitives with unchanged output for every existing call, and the preview practice screen's answer rows now use `AnswerChoice`. Everything else in the inventory above changes markup or appearance and is therefore scheduled for S03.6 with its own matrices, not done silently here.

**Proposals recorded for owner review** (conservative defaults implemented):

1. Loading placeholders are static (no shimmer), per the idle-motion budget in 02 §9.4.
2. A pending button swaps to its pending label and shows no spinner; a spinner would be an idle loop outside the budget.
3. Dark-mode elevation is `none` for every elevation token, per 02 §5; overlays in dark mode (S03.2) will separate by the `raised` surface step.
4. The avatar slot currently demonstrates the existing draft Dina square still, which includes the Diorama background. 02 §9.7 asks for transparent slots, so transparent avatar renders of all four characters are an S03.4 asset task that needs the owner's first-family style approval.
5. Generic date entry uses the native date input for accessibility; its displayed format follows the device's locale, not the page language (observed: an es-MX page on an en-US browser shows `09/24/2026`). The age screen keeps its three-field day/month/year pattern.

## S03.2 implementation and rationale

All in `frontend/src/rebuild/design/` and exported from `controls.tsx`. No component owns a string; every label, heading and message is passed in translated.

**Layer infrastructure** (`layers.ts`). Every overlay renders into its own body-level host (`.lf-rebuild.lf-layer-root`), so it is `position: fixed` against the real viewport and never inside a scrolling, transformed or contained ancestor (02 rule 12). The host copies the surface's theme, language and age band from `RebuildProvider`, so a dialog on a dark es-MX surface is dark and es-MX although it is outside the surface's DOM. One module-level stack orders every dismissable layer: Escape closes only the topmost; while a modal layer is open every other child of `<body>` is `inert` except the layers opened after it and the live hosts (announcer, toasts), so an announcement made during a dialog is still heard. Scroll lock sets `overflow: hidden` on the root, compensates the scrollbar gutter, is reference-counted for stacked modals and restores the exact position if anything moved it (rule 13). The focus trap focuses the requested element, else the first tabbable, else the panel; wraps Tab and Shift+Tab; and on close returns focus to what had it, or to the last pressed control when a browser (Safari) did not focus a clicked button. The z-index order is generated into `tokens.css` as `--layer-nav`, `--layer-sheet`, `--layer-scrim` and `--layer-toast` (30/50/65/70) by `build-rebuild-tokens.mjs` from the Bible's own sentence, so `spec:check` fails if either drifts, and a contract test refuses any other `z-index` value.

**Overlays** (`overlays.tsx`, `overlays.css`):

## S03.3 implementation and rationale

**One glyph source (07 §2).** The manifest (`src/rebuild/assets/manifest.json`) now carries the system glyphs as class A rows, one row per family (`show`/`hide` share one), each with its path data and the single declared source `littlefounders-in-house`. `glyphs.tsx` holds no path data: it reads the class A rows and only mirrors their names (`GLYPH_NAMES`) for the type system. The asset gate fails when: there are more than 24 families; a row declares a second source; a row lacks the decorative, both-modes, system-slot shape or carries a file path or review status; a family id does not name its glyphs; a glyph outside the 07 §2 starting list has no `reason`; a path is not plain path data or leaves the 20 px live area of the 24 px grid (curves and arcs are sampled, so an arc that bulges past the padding is caught); a starting-list glyph is missing; `GLYPH_NAMES` differs from the manifest; `glyphs.tsx` carries path data; any other rebuilt file draws a `viewBox="0 0 24 24"` icon; or a rebuilt file imports an icon or avatar pack (lucide, react-icons, heroicons, MUI icons, tabler, phosphor, feather, Font Awesome, Radix icons, Iconify, DiceBear). ## S03.7 implementation and rationale (motion)

A second claimant of a slot is refused and stays still; it takes the slot when the holder leaves. The compact Mentor stage claims `hero` for the character's catalogue idle (08 §3: the Mentor takes the hero object's place); a static still claims nothing. Claimed elements carry `data-idle-motion`.
- **Milestone celebration** (D7, OD-7, 07 §5). `Celebration` renders only for a milestone on the closed list in `milestones.ts`; anything else renders `data-refused` and never plays. It plays once per moment (`milestone` plus `momentId`, remembered for the session), then settles on `animationend` or a 1.2 s timer, so a hidden tab still settles. Parts are marked with `celebrationPart`: the medal pops on `--ease-spring` over `--dur-celebration`, tiles rise in sequence and bars fill. `CountUp` counts with tabular digits in a box already as wide as the final value, so nothing reflows. The lesson result screen (lesson complete, on the list) is the first product use; its Continue is the screen's one breathing call to action.
- **Loading is still.** The transport "opening" screen's infinite progress animation (recorded in S03.1) is removed: a loading state is not one of the three idle loops. Its matrix now fails on any infinite animation there.

**Enforcement.** `controlsCss.test.ts` fails when any rebuilt stylesheet loops (`infinite`) anywhere except the breathing button, uses `--ease-spring` or `--dur-celebration` outside the motion sheet's playing-celebration rules, or animates outside a `prefers-reduced-motion: no-preference` query. `motion.test.tsx` pins the armed bump, the answer grammar, the one-breathing-button rule and its hand-over, the three-slot cap, the closed list, once per moment, the reduced-motion static frame, the count-up width and the result screen's use.
