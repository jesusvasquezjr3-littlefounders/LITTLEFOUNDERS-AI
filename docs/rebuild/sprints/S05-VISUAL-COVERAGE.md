### M1 controlled engine candidate

One reusable 6–9/10–12 concrete → pictorial → abstract addition candidate preserves the same bounded problem across three authored stages. It uses in-house object groups, pictorial groups and a final native symbolic input; stage-specific worked steps strictly decrease. Concrete support now tells the learner to start with the first group, count the second group and name the total; pictorial keeps the first two prompts and abstract removes them. Each stage carries localized authored `spokenText`, used as the representation's accessible name; a missing value is rejected by both document contracts. The refreshed 96/96 browser matrix in `audit-results/rebuild-cpa-fading/` passed with no static visual findings, and the 6–9 Spanish light view was inspected with those support prompts. On narrow layouts Check remains in the safe-area-aware lesson foot. A representation handoff enters and exits with bounded shared motion and is absent under reduced motion; an initial 24 wide-state overflow finding was corrected by containing the transient paint in the CPA surface before the final 96/96 pass. Core rejects a direct later-stage request unless it has a same-run receipt for the preceding representation, then records the first met stage from immutable metadata and a receipt, never a browser field. The authenticated route proves a concrete review, pictorial met response and final abstract met response before version-pinned save. On recovery, Core returns public attempted stage IDs separately from met IDs, and the browser uses them only to reopen the next CPA stage; malformed, non-prefix or completion-bypassing recovery cannot reach an exercise. A grade-transport failure keeps the response and token in place with localized retry copy rather than presenting a learning review. The board reaches its finish surface only after that final symbolic stage is met, and an active final review retains the symbolic response with its replacement token. Core completion requires that same final receipt rather than forcing prior reviewed representations to be resubmitted. Mentor support attribution, physical database proof, adaptive pathway branching, publication and owner acceptance remain open.
