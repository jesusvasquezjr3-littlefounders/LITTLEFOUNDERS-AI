**Decisions taken on the conservative default (proposals for owner review).**

1. V-04: the shimmer and the spinner are budgeted as busy motion, not as idle slots; the owner's answer asks for them alongside the three-thing idle budget, and counting them as idle would refuse a loading screen that also has a breathing call to action.
2. V-04: dark shadow strength is derived (4x the light opacity, capped at .6, in the dark `sunken` colour) rather than a new hand-picked token; the Bible's token block has no dark elevation values.
3. V-12: the confetti is a Lottie played by the already-bundled dotLottie player, loaded only when a lesson-complete moment plays; the static frame is a separate registered SVG rather than a frame number, so reduced motion never loads the player.
4. V-12: hues are reward, mint and berry (07 §3 caps art at 3 hues); the W2L.4 CSS pieces also used sky and a neutral.
5. V-13: the compact size applies only below a 640 px container; wider screens keep the standard control.
6. V-14: links and the wordmark use `primary-strong` in dark mode (the dark `primary` wordmark would be too dim); the call to action keeps the accent fill in both modes.
7. L-02: the Mentor's live activity also plays the success cue on a right answer, as the v2 lesson does, so a miss is not the only sound.
