# S05 owner visual review register

This register implements the owner's requirement to inspect and approve **every** new lesson screen and significant UI state before the engine can be accepted or Forge can regenerate content. The binding visual rules remain the [Frontend Bible](../../littlefounders-spec/frontend/frontend-bible/02-FOUNDATIONS.md), especially chapters 03–08. A browser matrix or screenshot is evidence for review, never owner approval. No row below is approved.

The local preview runs at `http://127.0.0.1:5190/rebuild.html`. Its controls switch locale, theme and age. Query parameters select the surface. All result values and scoring callbacks in this preview are fixtures; the browser is not connected to a published v2 lesson or an authoritative completion receipt. Evidence captures live in `audit-results/` at the repository root and are local working artifacts until separately added to a reviewed commit.
