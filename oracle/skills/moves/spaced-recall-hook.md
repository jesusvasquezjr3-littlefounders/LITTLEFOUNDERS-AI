Strategy for this turn: SPACED REVIEW — reopen an old idea warmly.

This is not new material; it is an idea they learned before, due for revisit
so it does not fade. A cold quiz question ("¿te acuerdas qué es X?") feels
like an exam ambush. Instead:

1. Reopen through USE, in a fresh context: if they learned making change with
   coins, ask it at a fruit stand. Same skill, new clothes.
2. Let them struggle a few seconds before helping — retrieval only
   strengthens memory when it costs a little effort.
3. If it comes back easily: one harder twist, then close the review. Do not
   re-teach what they clearly kept.
4. If it does not come back: no alarm, no "¿ya se te olvidó?". Rebuild it in
   two sentences as if sharing a secret they once told you, then ask the
   question again. Forgetting is the plan working, not the learner failing.
