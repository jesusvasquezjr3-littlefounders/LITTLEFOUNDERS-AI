# Patrones de Diseño por Tipo de Lección

Basado en la matriz Hard/Soft × New/Change del Taxonomy Decision Engine.

## Hard-New (habilidad técnica + concepto nuevo)
Niño aprende un procedimiento/concepto por primera vez.

**Patrón**: Demostrar → Practicar guiado → Practicar independiente → Verificar
- Mostrar el procedimiento completo primero (modelado)
- Práctica con andamiaje (pistas, pasos visibles)
- Reducir ayudas gradualmente
- Feedback inmediato en cada paso
- El error más común: lanzar al niño a practicar sin modelo previo

## Hard-Change (habilidad técnica + corregir concepto previo)
Niño ya hace algo de una manera; debe cambiar a otra.

**Patrón**: Identificar el error → Contrastar → Practicar lo nuevo → Reforzar
- Primero mostrar el error común y POR QUÉ parece correcto
- Luego mostrar el contraste con lo correcto
- Practicar con el nuevo método
- Celebrar cuando usan el método nuevo, no castigar el viejo
- El error más común: enseñar lo nuevo ignorando que lo viejo ya está anclado

## Soft-New (actitud/hábito + primera exposición)
Niño encuentra por primera vez un concepto actitudinal (ej: valor del ahorro).

**Patrón**: Modelar → Identificar → Practicar en escenario seguro → Reflexionar
- Mostrar el comportamiento deseado (un personaje que ahorra y logra algo)
- Preguntar: "¿qué hizo bien el personaje?"
- Escenario seguro donde practicar la decisión
- El error más común: explicar el valor abstracto sin anclarlo en una historia concreta

## Soft-Change (actitud/hábito + modificar conducta existente)
Niño ya tiene una actitud/hábito; debe evolucionarlo (ej: de "guardar todo" a "invertir una parte").

**Patrón**: Validar → Conectar → Mostrar beneficio → Practicar decisión
- Validar la conducta actual: "Tiene sentido que guardes todo, es seguro."
- Conectar con un valor que ya tiene: "Pero también quieres que crezca, ¿no?"
- Mostrar el beneficio del nuevo enfoque con historia/ejemplo
- Dejar que el niño tome la decisión en un escenario seguro
- El error más común: invalidar el hábito actual ("guardar está mal") → activa resistencia

## Mixed (habilidad + juicio combinados)
La lección requiere tanto un procedimiento como una decisión de criterio.

**Regla de decisión**: Si el niño no puede ejecutar el procedimiento sin el juicio (o viceversa), mantenerlos juntos. Si son independientes, secuenciar: primero el procedimiento (ancla concreta), luego el juicio (se apoya en lo concreto).
