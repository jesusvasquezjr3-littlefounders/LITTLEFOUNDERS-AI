# Evaluación de Lecciones — Arquitectura

## Principio Rector

La evaluación se diseña junto con la lección, no después. Secuencia backward:
1. Definir qué resultado se busca (¿qué hará diferente el niño?)
2. Determinar qué conductas observables producen ese resultado
3. Diseñar ejercicios que confirmen esas conductas
4. Recoger feedback para mejorar la experiencia

## Niveles de Evaluación

| Nivel | Qué Mide | Cómo se Mide |
|-------|---------|-------------|
| **L1 — Reacción** | ¿Le gustó? ¿Le pareció relevante? | Encuesta simple post-lección (emojis, estrellas) |
| **L2 — Aprendizaje** | ¿Aprendió el concepto? | Ejercicios dentro de la lección (correcto/incorrecto + feedback) |
| **L3 — Transferencia** | ¿Aplica lo aprendido fuera de la lección? | Desafío de aplicación (tarea real asignada) |
| **L4 — Impacto** | ¿Cambió su comportamiento financiero? | Métrica observable (ej: decisiones de ahorro) |

## Para Lecciones Infantiles

- L1: Usar escalas visuales (caritas, estrellas), no escalas numéricas 1-5
- L2: Cada ejercicio ES evaluación. El feedback explica el porqué. No separar "enseñanza" de "evaluación"
- L3: Incluir al final de cada lección un mini-desafío para aplicar fuera: "Muéstrale a un adulto lo que aprendiste" o "La próxima vez que vayas a la tienda, fíjate en..."
- L4: Medir a nivel de aventura, no de lección individual. Comparar antes vs después de completar la aventura.

## Timing

La infraestructura de medición debe existir ANTES de lanzar la lección. Sin línea base pre-intervención, no hay forma de atribuir cambios a la lección.
