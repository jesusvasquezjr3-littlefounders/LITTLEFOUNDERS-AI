# Motor de Clasificación de Lecciones

Clasifica cada lección en dos ejes para determinar el enfoque de diseño:

## Matriz de Clasificación

| | Habilidad Dura (Hard) | Habilidad Blanda (Soft) |
|---|---|---|
| **Concepto Nuevo** | Hard-New | Soft-New |
| **Cambio de Conducta** | Hard-Change | Soft-Change |

- **Hard**: habilidades técnicas, procedimientos, reglas, cálculos, hechos
- **Soft**: actitudes, mentalidad, hábitos, habilidades interpersonales, valores
- **New**: el niño no tiene experiencia previa con este concepto
- **Change**: el niño ya tiene una idea/conducta que debe evolucionar o corregirse

## Señales de Clasificación

### Señales de "New":
- El concepto no aparece en prerrequisitos de aventuras anteriores
- Es la primera vez que el niño encuentra esta idea en el currículo
- No hay concepciones erróneas previas que deshacer

### Señales de "Change":
- El niño ya tiene un modelo mental (aunque sea incorrecto)
- La lección redefine o expande un concepto visto antes
- Hay hábitos que necesitan modificarse, no solo aprenderse

## Priorización MVP por Tipo

| Tipo | Enfoque Prioritario |
|------|---------------------|
| **Hard-New** | Claridad de procedimiento, práctica guiada → independiente, feedback inmediato |
| **Hard-Change** | Identificar el error común primero, mostrar contraste con lo correcto, práctica con el nuevo método |
| **Soft-New** | Modelado (mostrar el comportamiento), identificación ("cuál es la mejor respuesta"), práctica en escenarios seguros |
| **Soft-Change** | Empatizar con la dificultad del cambio, valores compartidos como puente, "qué ganas con el nuevo enfoque" |
| **Mixto** | Secuenciar: Hard primero (lo concreto ancla), Soft después (lo abstracto se apoya en lo concreto) |

## Protocolo de Confianza

Si la clasificación no es clara, hacer dos cosas:
1. Revisar los prerrequisitos declarados en el currículo
2. Adoptar la clasificación más conservadora (asumir "New" si hay duda)
