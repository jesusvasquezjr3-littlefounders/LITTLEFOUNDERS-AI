# Ship-First Design — Diseño Backward para Lecciones

En lugar de empezar con "¿qué quiero enseñar?" y luego añadir ejercicios, se empieza con "¿qué va a PRODUCIR el niño?" y se diseña hacia atrás.

## Las 3 Etapas

### Etapa 1: Definir el entregable
- ¿Cuál es el resultado tangible de esta lección? (una decisión, un cálculo, una comparación, una clasificación)
- ¿Qué debe ser capaz de HACER el niño al final?
- ¿Qué modelo mental debe tener?
- ¿Qué vocabulario debe reconocer?

### Etapa 2: Definir la evidencia
- ¿Cómo sabré que lo logró? (ejercicio correcto, decisión justificada, explicación con sus palabras)
- ¿Qué tipo de ejercicio demuestra cada nivel de Bloom?
- ¿El ejercicio realmente evalúa el objetivo o solo evalúa memoria?

### Etapa 3: Diseñar el camino
- Solo incluir contenido que conecte directamente con el entregable
- Cada ejercicio debe ser un escalón hacia el entregable final
- Eliminar todo lo que no contribuya al objetivo (evitar "coverage obsession")

## Checklist de Alineación

Para cada lección, verificar:
- [ ] ¿El objetivo de la lección dice lo que el niño va a HACER (verbo concreto)?
- [ ] ¿Los ejercicios requieren el mismo nivel cognitivo que el objetivo?
- [ ] ¿El feedback enseña o solo marca correcto/incorrecto?
- [ ] ¿Hay al menos un ejercicio donde el niño deba DECIDIR (no solo recordar)?
- [ ] ¿El cierre conecta con algo que el niño pueda aplicar fuera de la lección?
