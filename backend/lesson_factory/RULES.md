# 📘 `RULES.md` | Content Quality Standards: Business & Finance Education
> **Propósito:** Criterios de calidad para crear lecciones de Finanzas, Economía, Administración, Banca y Emprendimiento. Enfocado en **contenido pedagógicamente efectivo**, adaptable a usuarios de **6 a 17+ años**. Basado en progreso por lecciones, no por tiempo.

---

## 🎯 1. PRINCIPIOS FUNDAMENTALES (NO NEGOCIABLES)

```
✅ Cada lección debe:
   • Enseñar mediante acción (decidir, calcular, analizar), no solo lectura pasiva
   • Limitarse a 5-7 conceptos nuevos máximo
   • Anclar cada concepto a una situación real comprensible para la edad objetivo
   • Incluir feedback que explique el "por qué" del error, no solo marcarlo
   • Requerir ≥80% de precisión para avanzar al siguiente concepto

❌ Nunca:
   • Usar jerga sin definición contextual inmediata
   • Presentar fórmulas sin unidades, rango típico o propósito claro
   • Asumir conocimientos previos no declarados como prerrequisito
   • Priorizar entretenimiento sobre comprensión verificable
```

---

## 👥 2. ADAPTACIÓN POR GRUPO DE EDAD

| Grupo | Enfoque | Lenguaje | Ejemplos | Interacción |
|-------|---------|----------|----------|-------------|
| **6-8 años** | Concreto, visual, narrativo | Palabras simples, frases cortas, cero abstracciones | Ahorrar para un juguete, intercambiar cromos, "tiendita" | Arrastrar, emparejar, seleccionar con imágenes, audio opcional |
| **9-11 años** | Lúdico con lógica básica | Oraciones cortas, analogías cotidianas, jerga definida al instante | Mesada semanal, venta de limonada, comparar precios | Cálculos simples, decisiones binarias, mini-casos ilustrados |
| **12-14 años** | Contexto social + lógica aplicada | Lenguaje claro, introducción controlada de términos técnicos | Presupuesto para salida con amigos, primer emprendimiento escolar | Escenarios con 2-3 variables, comparaciones, justificación breve |
| **15-17 años** | Pensamiento crítico + aplicación real | Lenguaje técnico preciso con definiciones integradas | Evaluar becas vs. trabajo, análisis de ofertas, inversión básica | Casos con múltiples criterios, trade-offs, proyecciones simples |
| **18+ años** | Rigor profesional + transferencia inmediata | Lenguaje técnico estándar del dominio | Valuación de proyectos, análisis de riesgo, estrategia de precios | Problemas abiertos, evaluación de alternativas, recomendaciones accionables |

### 🔹 Reglas Transversales de Adaptación
- **Progresión Vertical**: Un mismo concepto debe poder enseñarse en los 5 niveles, aumentando complejidad, no cambiando el núcleo
- **Andamiaje Automático**: Si un usuario muestra dificultad, simplificar temporalmente sin cambiar de tema
- **Contexto Relevante**: Los ejemplos deben resonar con la realidad del grupo etario
- **Diseño Inclusivo**: Evitar estereotipos de género, rol o contexto socioeconómico

## 🧠 3. ESTRUCTURA COGNITIVA DE CADA CONCEPTO

Todo concepto nuevo debe seguir esta secuencia mínima:

```
1. ¿POR QUÉ IMPORTA? → Anclaje motivacional contextualizado por edad
2. ¿QUÉ ES? → Definición operativa en lenguaje apropiado al grupo etario
3. ¿CÓMO SE USA? → Mecanismo, fórmula o criterio de aplicación con ejemplo guiado
4. ¿QUÉ ERROR EVITAR? → Malentendido común + corrección clara
5. ¿CON QUÉ SE RELACIONA? → Conexión con 1-2 conceptos previos o siguientes
```

### 🔹 Tipos de Ejercicio por Objetivo
| Objetivo | Tipo de Ejercicio | Ejemplo (Grupo 12-14) |
|----------|------------------|----------------------|
| **Reconocer** | Clasificación, identificación | "¿Cuál de estos es un gasto fijo?" |
| **Calcular** | Cálculo guiado con datos reales | "Si ahorras $20/lección, ¿cuánto tendrás en 5 lecciones?" |
| **Comparar** | Análisis de alternativas | "¿Conviene más una tarjeta con 0% anualidad y 28% CAT, o una con $500 anualidad y 18% CAT?" |
| **Decidir** | Escenario con criterios múltiples | "Tienes $1,000: ¿los gastas, ahorras o inviertes? Justifica con 2 razones" |
| **Aplicar** | Caso breve integrado | "Este negocio vende a $50, cuesta $30 producir y tiene $1,000 fijos/mes. ¿Cuántas unidades necesita vender para no perder dinero?" |

## 📏 4. CRITERIOS DE PRECISIÓN DISCIPLINAR

| Dominio | Regla de Oro | Verificación Rápida |
|---------|-------------|-------------------|
| **Finanzas** | Toda métrica incluye: fórmula, unidades, rango típico, supuestos | ¿Se puede calcular con los datos dados? ¿El resultado es realista? |
| **Contabilidad** | Distinguir claramente entre principio normativo y práctica operativa | ¿Queda claro si es regla obligatoria o recomendación? |
| **Economía** | Presentar modelos como herramientas con límites, no como verdades absolutas | ¿Se mencionan los supuestos clave del modelo? |
| **Emprendimiento** | Priorizar validación empírica sobre teoría no probada | ¿El consejo se basa en evidencia o en opinión? |
| **Banca/Riesgo** | Contextualizar regulatoriamente cuando aplique | ¿Queda claro si es práctica general o requisito legal específico? |
| **Administración** | Herramientas con criterios claros de cuándo usarlas | ¿Se explica en qué situaciones esta herramienta es útil (y cuándo no)? |

## 🔄 5. PERSONALIZACIÓN Y REPETICIÓN ESPACIADA (POR LECCIONES)

### 🔹 Señales para Adaptar Contenido
| Si el usuario... | Entonces el contenido debe... |
|-----------------|------------------------------|
| Falla 2 veces en el mismo concepto | Ofrecer analogía alternativa + ejemplo más concreto + desglose paso a paso |
| Responde rápido y con precisión | Introducir complejidad gradual o contexto más ambiguo |
| Muestra preferencia por casos prácticos | Incrementar ejercicios tipo escenario vs. cálculo mecánico |
| Tiene dificultad con abstracciones | Anclar en ejemplos tangibles antes de generalizar |
| Busca aplicación inmediata | Priorizar ejercicios con output accionable ("calcula tu ahorro mensual") |

### 🔹 Lógica de Repetición Espaciada (Basada en Lecciones)
- Cada concepto debe reaparecer en **3 momentos**: 
  1. Práctica inicial (misma lección o siguiente)
  2. Revisión a las **3-5 lecciones posteriores**
  3. Aplicación integrada en contexto nuevo (**8-12 lecciones después**)
- Las revisiones deben **variar el formato** del ejercicio, no repetir el mismo ítem
- Conceptos con alta tasa de error histórico deben tener **más puntos de re-encuentro** programados

## 📊 6. MÉTRICAS DE CALIDAD (EVALUACIÓN DE CONTENIDO)

| Métrica | ¿Qué mide? | Umbral Mínimo |
|---------|-----------|--------------|
| **Dominio Conceptual** | % que aplica correctamente el concepto en 3 contextos distintos | ≥70% |
| **Resolución de Errores** | % que corrige malentendido tras feedback instructivo | ≥75% |
| **Retención por Lecciones** | % que recuerda y aplica el concepto tras 5-8 lecciones posteriores | ≥60% |
| **Claridad Percibida** | % que califica la explicación como "clara" o "muy clara" | ≥80% |
| **Transferencia** | Precisión al aplicar concepto en escenario no visto durante la lección | ≥55% |

> 📌 **Validación obligatoria**: Cada lección nueva debe probarse con un grupo piloto del grupo etario objetivo antes de publicación masiva.

## ✅ 7. CHECKLIST RÁPIDO PRE-PUBLICACIÓN

```
PRECISIÓN
[ ] Fórmulas/métricas incluyen unidades y rango realista
[ ] Supuestos explícitos; se distingue hecho vs. teoría vs. práctica
[ ] Referencias normativas actualizadas y precisas

CLARIDAD
[ ] Términos técnicos definidos en contexto en primera aparición
[ ] Ejemplos progresan de concreto a abstracto
[ ] Feedback anticipa y corrige errores comunes

RELEVANCIA
[ ] Concepto anclado a decisión/situación real del mundo de los negocios
[ ] Datos y escenarios verosímiles y actualizados
[ ] Se explicita cuándo aplica (y cuándo no) el principio enseñado

ADAPTACIÓN POR EDAD
[ ] Lenguaje, ejemplos e interacción alineados al grupo etario objetivo
[ ] Mismo concepto puede escalarse verticalmente a otros grupos de edad
[ ] No se asumen conocimientos previos no declarados

INCLUSIVIDAD
[ ] Lenguaje claro sin sacrificar precisión técnica
[ ] Ejemplos consideran diversidad de contextos
[ ] Sin sesgos implícitos de género, rol o nivel socioeconómico
```

> ⚠️ **Si falla cualquier ítem**: Revisar antes de publicar. No compensar calidad con engagement superficial.

## 🔄 8. MEJORA CONTINUA

```
1. MONITOREAR → Revisar por lote de lecciones las métricas de efectividad
2. ESCUCHAR → Incorporar feedback cualitativo de usuarios y educadores
3. ACTUALIZAR → Revisar contenido ante cambios regulatorios o de práctica
4. ITERAR → Modificar lecciones con bajo desempeño en dominio o transferencia
5. DOCUMENTAR → Registrar ajustes y su justificación pedagógica
```
